Compression Pipeline

Image/Video Integrated Compression System used in our research.

Overview

This project provides a command-line interface (CLI) pipeline for automating image and video compression. It allows users to easily encode various media files using different codecs (HEVC, AVC, JPEG) and quality settings through a single, unified command structure main.py.

Key Features

  • Unified Interface: A single main.py script handles all codec operations.
  • Multiple Codecs: Supports HEVC (H.265), AVC (H.264), and JPEG.
  • Flexible Input: Processes single files or entire directories recursively.
  • Quality Control: Easy QP/Quality setting via --QP argument.
  • Encoding Modes: Supports Standard (Random Access) and All-Intra modes.

Usage Guide

General Command

python3 main.py \ --codec \ --QP \ --input \ --output \ [OPTIONS]

Replace <CODEC> with HEVC, AVC, or JPEG.
Replace <VALUE> with the desired quality factor or QP.

Argument Reference

Argument Description
--codec Codec to use: HEVC, AVC, JPEG
--QP Quality parameter (Lower=Better for Video, Higher=Better for JPEG)
--preset Speed preset (e.g., fast, medium, slow). Default: medium
--all_intra Use All-Intra mode (every frame is a keyframe)

Examples

HEVC Encoding (Random Access)

Standard video compression with GOP structure.

python3 main.py --codec HEVC --QP 27 --input video.mp4 --output ./out --preset fast

HEVC Encoding (All-Intra)

Every frame encoded as a keyframe.

python3 main.py --codec HEVC --QP 27 --input video.mp4 --output ./out_ai --all_intra

AVC (H.264) Encoding

python3 main.py --codec AVC --QP 30 --input video.mp4 --output ./out_avc --preset ultrafast

JPEG Compression

python3 main.py --codec JPEG --QP 90 --input image.png --output ./out_jpeg

System Requirements

  • Python 3: For running the main script.
  • FFmpeg: Required for AVC and HEVC encoding/decoding. Must be in system PATH.
  • Pillow: Python library for JPEG handling (pip install Pillow).
